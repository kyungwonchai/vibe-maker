# Vibe Maker (바이브 메이커)

AI 에이전트(Antigravity CLI 등)와 연동하여 자연어 프롬프트를 바탕으로 애플리케이션 자동 생성, 유지보수, 실행 및 실시간 모니터링을 지원하는 통합 개발 관리 도구입니다.

## 주요 기능
- **실시간 실행 세션 모니터링**: 백그라운드 터미널(tmux 등)을 통한 에이전트 작업 모니터링
- **앱 목록 및 로그 관리**: kwsoft 내 전체 앱 현황 파악 및 30일간의 명령어/실행 히스토리 확인
- **프롬프트 기반 자동화**: 자동 테스트 및 기능 개발 파이프라인 수행
